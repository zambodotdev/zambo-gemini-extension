# Zambo: Gemini CLI extension

The verifiable work layer for AI, as a Gemini CLI extension. One keyless remote MCP endpoint, https://zambo.dev/mcp, serving 153 tools (36 on the default surface). Every call returns a verifiable AER-1 receipt (IETF Internet-Draft draft-zambo-aer1-26), checkable at https://zambo.dev/verify with no account.

Flagship: HANDOVER. Wrap up a session in one AI and pick the work up in another; both the wrap and the pickup leave receipts. Free tier: 20 calls + 1 wrap-up free every day; picking up in another AI is always free. Day Pass: $0.99 for unlimited calls for 24 hours. Zambo Pass: $29 for 30 days, $290 for 365 days, $19 for 30 days for $ZAMBO holders.

Install: `gemini extensions install https://github.com/zambodotdev/zambo-gemini-extension`
